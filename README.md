# 胡闹厨房 · 料理人格测试

一个微信原生小程序：用 16 道「厨房里的二选一」，测出你在灶台前的动物人格。每个结果对应一只动物、一间厨房、一张可以保存的海报。

> 16 QUESTIONS · 4 AXES · 16 PERSONAS
>
> 课程项目 · 原生小程序，无框架、无服务端，所有计算与存档都在本地完成。

## 它是什么

- **16 道题**：四个主题篇章（食材抉择 / 烹饪工序 / 风味哲学 / 动机与仪式）各 4 题，每题两个选项，都是「你会怎么做」而不是「你是什么样的人」。
- **4 个维度**：食材相性（C 守味 / A 越界）、制作工序（P 精准 / M 随性）、风味倾向（H 清淡 / E 重口）、动机诉求（S 省事 / I 仪式）。
- **计分规则**：只统计「左选项」。每维 ≥ 2 判为该维高位字母，四维拼接得到 4 位 code，共 16 种组合，全部可达、无空型。
- **16 张结果**：每型固定一只动物角色 + 一间厨房背景 + 四枚标签 + 一句评语 + 天生拍档 / 厨房克星，写进一张可直接渲染的卡。
- **海报**：结果页可生成 750×1250 的 canvas 海报，暖色面板 + 角色 + 五级信息，可保存到相册。

## 网页试玩版（可直接分享）

小程序本体只能在微信里打开，所以仓库里带了一个网页试玩版 `demo/`，用同一套题库、同一套计分、同一套 16 型文案与素材，任何浏览器打开即可玩。

- 在线地址：<https://1728917371-cmyk.github.io/hunaokitchen-miniprogram/demo/>
- 本地预览：在仓库根目录 `python3 -m http.server 8000`，打开 `http://localhost:8000/demo/`

网页版在小程序基础上补了两件事：结果页可直接生成 750×1250 海报图；最近结果存在浏览器 `localStorage`（不上传）。

## 目录结构

```
app.js / app.json / app.wxss   小程序入口与全局样式
pages/
  index/     首页：厨房背景 + 开始测试
  test/      答题页：16 题，二选一，进度条
  result/    结果页：角色 + 厨房 + 标签 + 评语 + 海报生成
  history/   历史记录：本地保存最近几次结果
utils/
  data.js    题库（16 题）、4 维定义、16 型文案与资源映射
  history.js 本地 storage 读写，记录最近结果
assets/
  results/   16 张角色 PNG（720×1280，透明底）
  kitchen/   16 张厨房背景 JPG（675×1200）
i18n/        文案基础表
```

## 本地运行

1. 用微信开发者工具「导入项目」，选择本仓库根目录。
2. `project.config.json` 里的 `appid` 是课程开发用的小程序 appid；换成自己的 appid 或使用测试号即可运行。
3. 编译后即可在模拟器里答题、看结果、生成海报。真机预览需要在小程序后台把微信号加为开发者或体验成员。

## 设计说明

- **视觉**：暖米白 `#FAF4E6` 打底、浅奶油 `#F3E2C4`、深棕文字 `#3B2A1E`、强调橙 `#B56A2E` / `#D97634`；圆角、细描边、暖色硬投影，不使用模糊阴影。
- **素材映射**：`utils/data.js` 里每个 code 绑定角色 PNG、厨房背景、四枚标签与一句评语。厨房图与人格的对应目前仍是设计期假设映射，未逐张确认，调整只需改 `kitchen` 字段，页面无需改动。
- **包体**：主包约 1.64 MB，图片全部压到 2 MB 限制内。
